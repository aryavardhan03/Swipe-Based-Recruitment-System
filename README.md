\# Swipe-Based Recruitment System



\## Overview

This project is a Swipe-Based Recruitment System that simplifies job matching using an interactive swipe interface and AI compatibility scoring.



\## Features

\- Swipe-based job discovery

\- Swipe-based candidate review

\- AI compatibility score

\- Real-time matching

\- Resume viewing



\## Technology Stack

Frontend: Flutter  

Backend: Firebase Firestore  

Cloud Platform: Google Firebase
